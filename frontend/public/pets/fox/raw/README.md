## 新素材语义拆分

这张图更适合做“补充动作包”，而不是整行替换。

| 图上行名 | 建议拆到的动作 | 说明 |
| --- | --- | --- |
| `Idle` | `idle`、`happy` 补帧 | 前几帧是站立待机，后几帧表情更开心，可以作为待机表情补充，不建议随机连续播完整行。 |
| `Walk` | `walk` 候选帧 | 这一行语义比较准，可以和真实位移绑定测试，但要确认脚步节奏和位移速度是否匹配。 |
| `Eat` | `eat`、`drink`、`sleep/nap` 拆开 | 这一行混了趴睡、吃碗、喝水滴、张嘴趴着等状态，不能整行当吃饭。 |
| `Drink` | `sleep/nap` 补帧 | 这一行大部分是趴睡加 `Z` 的状态，更像睡觉循环，不适合放到喝水动作。 |
| `Sleep` | `sleep`、`wake` 拆开 | 前几帧是睡觉，最后一帧像醒来/转身，不能放进睡觉循环里一直播。 |
| `Sad` | `sad` 新动作 | 可以在心情低、饥饿低、接口失败或用户点“安慰”时播放。 |
| `Angry` | `angry` 新动作 | 可以在连续打扰、拖拽太久、重复点击时播放；最后流泪帧更像委屈，可单独归到 `sad`。 |

## 推荐接入顺序

1. 先补 `sleep/nap`：从 `Drink` 行和 `Sleep` 行挑纯趴睡帧，让休息状态更稳定，不混入站起来或醒来帧。
2. 再补 `sad` 和 `angry`：这是现有宠物系统缺少的情绪层，能让互动更丰富。
3. 最后再测试新 `walk`：走路必须和真实位移速度一起调，不适合只替换图片帧。
4. `Eat` 行只挑带碗/水滴的局部帧：吃饭只用碗，喝水只用水滴，趴睡帧不要混进去。

## 行为逻辑建议

宠物播放优先级保持：

`拖拽 > 睡觉 > 一次性互动动作 > 走路巡游 > 待机`

新增动作不要自动乱播：

- `sad`：只在心情/饱食度低，或特定事件触发时播放一次。
- `angry`：只在连续点击/拖拽打扰时播放一次。
- `nap/sleep`：进入休息后只播放睡觉帧，不能混入醒来或站立帧。
- `eat/drink`：只播放各自语义明确的帧，避免吃饭时出现喝水或趴睡。
