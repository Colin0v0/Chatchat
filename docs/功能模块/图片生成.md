# 图片生成

更新时间：2026-04-27

## 1. 功能范围

图片生成是可选外部 API 能力。

支持：

- 根据 prompt 生成图片。
- 在新会话里生成图片。
- 在已有会话里生成图片。
- 保存生成图片到媒体目录。
- 生成 assistant 图片消息。

它不影响普通聊天，也不代表后端加载图片模型。

## 2. 后端 API

```text
POST /api/images/generate
```

关键文件：

- `backend/app/api/images.py`
- `backend/app/provider_transports/openai_images.py`
- `backend/app/storage/media.py`

## 3. 配置

```env
OPENAI_IMAGE_BASE_URL=
OPENAI_IMAGE_API_KEY=
OPENAI_IMAGE_MODEL=gpt-image-2
OPENAI_IMAGE_SIZE=1024x1024
OPENAI_IMAGE_QUALITY=auto
OPENAI_IMAGE_OUTPUT_FORMAT=png
OPENAI_IMAGE_TIMEOUT_SECONDS=180
```

支持格式：

- `png`
- `jpeg`
- `webp`

尺寸需要符合上游模型支持范围。

## 4. 保存流程

```text
prompt
  -> image generation API
  -> b64 或 URL
  -> 下载/解码图片
  -> 保存到 MEDIA_ROOT
  -> 创建 assistant message
  -> 关联 message attachment
```

## 5. 当前边界

- 不配置图片 API Key 时不可用。
- 不影响 DeepSeek。
- 不使用本地图片模型。
- 图片上传给聊天模型由模型目录控制，和图片生成是两条链路。
