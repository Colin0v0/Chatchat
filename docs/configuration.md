# 配置与环境变量

更新时间：2026-04-30

## 1. 配置加载

后端配置入口是 `backend/app/core/config.py`。

配置加载顺序：

1. `backend/.env`
2. `CHATCHAT_ENV` 或 `APP_ENV` 指向的命名环境文件
3. `CHATCHAT_ENV_FILE` 显式指定的文件
4. 系统环境变量

同名变量后加载的会覆盖先加载的。

## 2. 基础配置

```env
APP_ENV=default
APP_NAME=Chatchat API
CORS_ALLOWED_ORIGINS=http://127.0.0.1:5200,http://localhost:5200
DATABASE_URL=
REDIS_URL=
MEDIA_ROOT=./storage/media
```

说明：

- `DATABASE_URL` 指向 PostgreSQL。
- `REDIS_URL` 指向 Redis。
- `MEDIA_ROOT` 保存附件、生成图片、音频等媒体文件。

## 3. 模型配置

```env
MODEL_CATALOG_PATH=./model_catalog.json
MODEL_CATALOG_STRICT=true
DEFAULT_PROVIDER=
DEFAULT_MODEL=
```

模型能力由 `backend/model_catalog.json` 声明。具体 provider 的 base URL、API key、上游模型名由对应 provider 配置决定。

常见 provider 配置形态：

```env
OPENAI_BASE_URL=
OPENAI_API_KEY=

CLAUDE_BASE_URL=
CLAUDE_API_KEY=

GEMINI_BASE_URL=
GEMINI_API_KEY=
```

项目可以继续扩展其他 provider。新增 provider 时，应同时更新 provider registry 和模型目录。

## 7. 图片生成配置

```env
OPENAI_IMAGE_BASE_URL=
OPENAI_IMAGE_API_KEY=
OPENAI_IMAGE_MODEL=
OPENAI_IMAGE_SIZE=1024x1024
OPENAI_IMAGE_QUALITY=auto
OPENAI_IMAGE_OUTPUT_FORMAT=png
OPENAI_IMAGE_TIMEOUT_SECONDS=180
```

图片生成是独立能力，不影响聊天模型。

## 8. 并发与超时

```env
REQUEST_TIMEOUT_SECONDS=180
OPENAI_CONNECT_TIMEOUT_SECONDS=30
HTTP_POOL_MAX_CONNECTIONS=100
HTTP_POOL_MAX_KEEPALIVE_CONNECTIONS=20
MODEL_MAX_CONCURRENCY_PER_MODEL=2
```

这些配置影响外部 provider 请求、连接池和模型并发控制。
