更新时间：2026-04-27

本文档作为模块文档索引使用。每个功能或技术模块单独维护一份说明，避免一个大文档越写越难找。

## 当前部署口径

Chatchat 当前主线是纯 CPU + 云端 API：

- DeepSeek 官网 API 负责聊天模型。
- 百炼/DashScope 负责 embedding、rerank、网页搜索、ASR、云端 TTS。
- PostgreSQL + pgvector 和 Redis 作为基础设施，可本地 Docker 部署。
- 后端不再依赖 Ollama、本地 OCR、本地视觉模型、本地 ASR、本地 embedding、本地 reranker。
- DeepSeek 默认禁用图片上传。
